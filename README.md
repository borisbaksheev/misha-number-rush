# Misha's Number Rush

An original 3D arcade game for young children where you **are a living number**. Two modes,
chosen on the start screen:

- **Racing** – hold a finger to run, slide to steer, and run through glowing maths gates that
  physically transform your character: numbers merge, duplicate, split into companions, join back
  together and grow all the way to one million and beyond.
- **Sky Numbers** – fly through bright skies and choose which floating maths portal to fly
  through (+, −, ×, ÷). Collect number bubbles and steer around grumpy little storm clouds.

Built with Three.js + TypeScript + Vite as an installable, fully offline PWA. No backend,
accounts, ads, purchases or network services.

## Play online

**https://borisbaksheev.github.io/misha-number-rush/**

Open it in Safari on an iPad (no certificates, local server or settings needed). To install it
like an app: **Share → Add to Home Screen**, then open it once from the new icon while online so
it is saved for offline play. New versions are picked up automatically when the game is opened
or brought back to the foreground (never in the middle of a game).

The site is built and published by GitHub Actions (`.github/workflows/pages.yml`) on every push
to `feature/sky-numbers` or `main`: it runs the tests, builds with `BASE_PATH=/misha-number-rush/`
and deploys `dist/` to GitHub Pages. Local development certificates are never part of the site.

## Play

| Action | Touch (iPad) | Keyboard (desktop testing) |
| --- | --- | --- |
| Racing: run | Hold a finger anywhere | ↑ / W / Space |
| Racing: steer | Slide the finger left/right | ← → / A D |
| Racing: slow down | Lift the finger | release |
| Sky: fly left/right/up/down | Slide the finger (flying forward is automatic) | arrow keys / WASD |
| Pause, start again, main menu, sound | ❚❚ button (top right) | |

There is no game over in either mode: falling off the road puffs you back onto it, wrong turns
are fine, racing gates that cannot be used (for example 7 ÷ 2) fall asleep and let you through,
and in the sky every portal row always offers valid choices.

## Sky Numbers

You start as **8** and fly forward automatically. Every few seconds a row of **three or four
portals** floats across the sky, each with an operation chosen live for the number you are right
now (for 8, for example, +1, −3, ÷2 and ×10). Fly through the one you like:

- **Addition** – a smaller number spirals in and merges with you.
- **Multiplication** – you duplicate, glow and combine; for ×10, ×100 … shining zeros fly in and
  click onto the end of your number.
- **Division** – you split into equal living parts; the extra parts wave and fly away.
- **Subtraction** – a smaller number separates from you and floats away.

Choices are generated by the shared maths engine: always 3–4 distinct, whole-number results ≥ 1,
scaled to the number's size (100 offers things like +80, −10, ÷2, ×10). If division is impossible
(7, 13 …) the row shows three portals. Nothing is hard-coded to a fixed sequence.

A seeded route of about 70 seconds repeats endlessly with fresh randomness: open sky with number
bubbles, a colourful cloud tunnel, storm clouds, a white cloud canyon and five portal rows.
**Storm clouds** are dark but friendly: bumping one gives a puff of smoke and sparks, a short
slowdown and, if your number is even, halves it (16 → 8, shown as 16 ÷ 2 = 8). Odd numbers only
slow down, the value never drops below 1, and a short cooldown prevents repeated penalties. You
can always fly around them. Portals gently help the number line up, so a small child can't miss.

## Racing: what's in the first track

One 1.36 km sky loop (about 60–70 s per lap; you can keep driving lap after lap):

1. Start as **2**. A friendly **2** runs up and merges: **2 + 2 = 4**.
2. **Fork A** – choose **×2** (duplicate and combine) or **+4** – both make **8**.
3. Curved, banked elevated road with candy curbs, a neon ring **tunnel**, a rainbow and an
   **overpass** over the start straight.
4. **Boost pad → ramp → gap**: a spinning jump over the clouds.
5. **Bounce zone**: wobbling jelly bumpers (two of them sway) and a trampoline.
6. **÷2 portal**: 8 splits into two living **4**s; your companion runs beside you.
7. **Floating tiles** with open edges (fall off and you are rescued automatically).
8. **JOIN** arch: **4 + 4 = 8**.
9. **Fork B** – **+2** (→ 10) or **−3** (→ 5; the 3 bounces away).
10. Golden **×10 finale**: shining zeros fly in and click onto your number (**10 → 100**),
    with a big-number celebration.

From lap 2 the forks offer **×2 / ×10**, so you can grow 100 → 1,000 → … → 1,000,000 →
1,000,000,000 (the prototype's maximum), or follow the doubling path.

All maths lives in `src/math` and is independent of rendering. The character always shows the
team's real value; animations only visualise results that the maths engine already computed.

## Run locally

Requires Node.js 20+ (developed with Node 24).

```bash
npm install
npm run dev        # http://localhost:5173 (also printed with your LAN address)
npm test           # unit + gameplay simulation tests
npm run build      # type-check + production build into dist/ (with service worker)
npm run preview    # serve the production build on http://localhost:4173
npm run ipad       # build + serve over trusted HTTPS on the Wi-Fi (see "Installing on an iPad")
```

Useful URL options: `?debug` (FPS, draw calls, position), `?quality=high|medium|low`
(otherwise quality adapts automatically when the frame rate drops), `?nopause` (don't pause when
the page is hidden; for automated testing only).

The start screen shows the build version (git commit and build time) at the bottom, so you can
check which version an iPad is running.

## Installing from this Mac instead (local HTTPS, optional)

The public website above is the easiest way. This older route serves the game from the Mac
without the internet. Safari only enables offline mode (service workers) on a **trusted HTTPS** address. The game is
served from this Mac over the home Wi-Fi with its own small certificate authority (CA), which
you trust once on the iPad. Nothing is uploaded to the internet.

### 1. Start the HTTPS server on the Mac

```bash
npm run ipad
```

This builds the game, serves it on port 4173 and prints the address to open, for example
`https://<your-mac>.local:4173/`, plus the CA certificate's location
(`.cert/misha-local-ca.crt`). The first run creates the CA; later runs reuse it and issue a
fresh server certificate for the Mac's current name and IP address. Keep the terminal open and
both devices on the same Wi-Fi. If macOS asks whether `node` may accept incoming connections,
click **Allow**.

### 2. Trust the certificate on the iPad (once)

1. Send `.cert/misha-local-ca.crt` to the iPad: **AirDrop** it from Finder
   (`open -R .cert/misha-local-ca.crt`, then right-click → Share → AirDrop), or email it to
   yourself and tap the attachment in the iPad's Mail app. The iPad says **Profile Downloaded**.
2. On the iPad open **Settings → General → VPN & Device Management**, tap
   **Number Rush local CA (…)** under *Downloaded Profile*, tap **Install**, enter the passcode,
   tap **Install** again and then **Done**. ("Not Verified" is expected for a home-made
   certificate.)
3. Open **Settings → General → About → Certificate Trust Settings** and switch on
   **Number Rush local CA (…)** under *Enable full trust for root certificates*, then tap
   **Continue**.

The CA is restricted to `.local` names, `localhost` and private network addresses, so it cannot
be used to impersonate real websites. Its private key stays in `.cert/` on the Mac and is never
committed. To undo, remove the profile in **Settings → General → VPN & Device Management**.

### 3. Install the game

1. In **Safari** on the iPad open the `https://<your-mac>.local:4173/` address printed by
   `npm run ipad`. It must load with no certificate warning. Prefer the `.local` name over the IP
   address: the Home Screen app remembers the exact address, and the IP can change.
2. Wait until the **Racing** and **Sky Numbers** buttons appear, then tap **Share** (in some Safari layouts it is in
   the **•••** menu) → **Add to Home Screen** → keep **Open as Web App** on if it is shown →
   **Add**.
3. Open the game once from the new Home Screen icon **while the Mac server is still running**
   and wait about 10 seconds. The Home Screen app has its own storage, so this first launch is
   what saves the game for offline play.

### 4. Check that it works completely offline

1. Stop the server on the Mac (**Ctrl+C**) and turn on **Airplane Mode** on the iPad (check that
   Wi-Fi is off too).
2. Close the game fully: swipe up from the bottom edge and swipe the game away in the app
   switcher.
3. Open it from the Home Screen icon. The start screen should appear, and both **Racing** and
   **Sky Numbers** (characters, portals, sounds and music) should work. If the iPad says it
   cannot open the page, repeat step 3 of *Install the game* with the server running and wait
   longer.
4. Turn Airplane Mode off again afterwards.

For offline play always use the Home Screen icon: a plain Safari tab can lose its offline copy
if the site isn't visited for a while.

**Updating:** after changing the game, run `npm run ipad` again and open the game from the Home
Screen while on the same Wi-Fi. The new service worker installs, takes over immediately and the
page reloads once with the new version; old cached files are deleted. Check the version stamp on
the start screen. When the Mac is unreachable the game simply keeps playing the saved version.

**If the game does not open:** the most common cause is that the server on the Mac is not
running (`npm run ipad` must be running for the first install and for updates; a plain Safari
tab needs it every time). A "This Connection Is Not Private" warning means the certificate is not
trusted yet (step 2). If the 3D view cannot start, the game now shows a "Try again" message
instead of a blank screen.

**Troubleshooting:** if the address doesn't open, check that the terminal still shows the server
and that the Wi-Fi isn't a guest network that isolates devices, then try the IP address the
script prints. If Safari shows a certificate warning, check that full trust (step 2.3) is on.
If the Mac's name changes, the Home Screen app points at the old address: add it again.

Quick testing without installing: run `npm run dev`, open the printed `http://<LAN-IP>:5173`
address in Safari on an iPad on the same Wi-Fi. Everything except offline caching works.
Any static HTTPS host can also serve `dist/` (relative paths are used, so a sub-folder works).

## Project layout

```
src/app.ts        shared shell: one renderer, sound, HUD, input, quality; game-mode switching
src/main.ts       menus and buttons
src/math/         numberMath.ts (operations, formatting, words), team.ts (split/join state),
                  random.ts (seeded random)
src/game/         Racing mode: course.ts (track data), raceLogic.ts (headless physics + gates),
                  transforms.ts (merge/split/zero animations), game.ts (orchestration),
                  cameraRig.ts, input.ts (shared touch/keyboard input), trackPath.ts
src/sky/          Sky Numbers mode: skyLogic.ts (headless flight, portals, storms, bubbles),
                  choices.ts (live portal operations), skyCourse.ts (seeded endless route),
                  skyFx.ts (transformations), skyVisuals.ts (clouds, portals, storms, trails),
                  skyGame.ts (orchestration)
src/render/       numberCharacter.ts, glyphs.ts, trackMesh.ts, environment.ts, items.ts,
                  particles.ts, sweep.ts, palette.ts
src/audio/        sound.ts (procedural Web Audio effects + music)
src/ui/           hud.ts, styles.css
tests/            maths, racing course invariants and full-lap route simulations,
                  sky portal choices, storms and flight simulations
scripts/          build-font.mjs (font → 3D glyph JSON), make-icons.mjs (app icons),
                  https-preview.mjs (local CA + HTTPS server for the iPad)
```

## Known limitations

- Performance and touch feel of both modes have been checked in a desktop browser with
  tablet-sized viewports only; they still need verification on a real iPad (target 60 FPS,
  adaptive quality is in place).
- No number narration yet (postponed until high-quality offline voice clips are available).
- One track; values above one billion are not supported (gates fall asleep instead).
